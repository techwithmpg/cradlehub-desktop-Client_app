# One UI system direction

Stage 00 direction, pending owner acceptance. The sole renderer entry is src/App.tsx; src/styles.css is the only token/style source. Tailwind 4's @theme holds semantic canvas, surface, ink, muted, line and accent colors with Segoe UI system typography. Native window decorations remain enabled. The initialization panel has no operational navigation or dashboard.

Later authorized UI work should extend this same token file and React component structure. Use shadcn-style local component ownership with Base UI for interactive accessibility primitives, CVA for meaningful variants, Lucide as the one icon family, and restrained Motion only when an interaction warrants it. Base UI, CVA, and Motion are deliberately deferred until a real authorized control needs them; no parallel library/gallery is scaffolded.

The eight approved PNGs under docs/20-product/reference-ui/current/crm retain their bootstrap-manifest.json SHA-256 values. They define hierarchy/density/layout/interaction/visual intent only. Their records, counts, totals and connection labels are not data contracts. Customers has no supplied reference image. No prior desktop implementation was imported.

The initialization screen uses semantic main, heading, section and definition-list elements, readable contrast, system fonts and no animation. There are no application controls to keyboard-test at this stage. Native observation and its limits are recorded in Stage 00 evidence; module viewport acceptance remains later-stage work.
